### Featured Projects

#### QuoteAI — Multi-Agent AI Insurance Underwriting

An end-to-end **multi-agent insurance underwriting system** built with LangGraph and XGBoost.

* Processes **146K+ insurance records** to predict driver risk tiers and policy conversion probability.
* Uses four specialized agents: **Risk Profiler, Conversion Predictor, Premium Advisor, and Decision Router**.
* Integrates **SHAP, SMOTE, and Isolation Forest** for explainability, class balancing, and anomaly detection.
* Deployed with **FastAPI + Next.js** and presented at the **GITAM Hackathon 2026**.

**Stack:** Python · LangGraph · XGBoost · FastAPI · SHAP · Scikit-learn · Groq · Next.js · Docker

#### MRI-Based Autism Spectrum Disorder Screening

A deep learning pipeline for screening **Autism Spectrum Disorder from structural MRI scans**.

* Built a 3-block CNN pipeline for 3D `.nii` MRI data.
* Used intensity normalization, mid-brain extraction, and slice-level prediction aggregation.
* Achieved **82.32% validation accuracy** and **0.878 AUC-ROC**.
* Investigated overfitting caused by correlated slice sampling and evaluated its impact on model performance.

**Stack:** Python · TensorFlow/Keras · OpenCV · NiBabel · NumPy · Scikit-learn

---

#### Multi-Agent Hedge Fund Simulation

A **multi-agent LLM trading system** built with LangGraph.

* Developed parallel analyst agents for **crypto, stocks, and forex** with structured, schema-validated outputs.
* Built a Fund Manager agent to convert analyst decisions into portfolio allocations.
* Replaced LLM-generated allocations with **mean-variance portfolio optimization** using historical volatility and correlations.
* Added volatility-triggered risk controls and a no-look-ahead historical backtesting framework.
* Improved the backtested Sharpe ratio from **-2.93 to +1.68** after identifying and correcting a risk-calibration issue.

**Stack:** Python · LangGraph · LLMs · SciPy · Portfolio Optimization
